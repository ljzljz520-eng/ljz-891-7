# 赛事裁判资格查询系统

面向赛事组委会的裁判资格核验平台：公众可凭 **裁判编号 + 姓名** 查询裁判的级别、执裁项目、
资格有效期、发证单位及最近培训记录；管理员登录后台后可新增、编辑、停用资格，并维护培训记录。

## 技术栈

- 后端：PHP 7.4+ / 8.x（PDO，无框架）
- 数据库：SQLite（文件存储，位于 Web 根目录之外）
- 前端：原生 HTML / CSS / JavaScript，无外部依赖

## 目录结构

```
referee-system/
├── app/                 # PHP 后端（不在 Web 根目录，无法直接访问）
│   ├── config.php       # 配置（初始管理员、级别字典、到期阈值）
│   ├── bootstrap.php    # 统一引导、异常处理
│   ├── db.php           # PDO 连接
│   ├── auth.php         # 会话、登录鉴权、CSRF
│   ├── helpers.php      # JSON 响应、表单校验、状态计算
│   └── init.php         # 建表 + 初始数据（自动执行，幂等）
├── public/              # Web 根目录（php -S 指向此处）
│   ├── index.php        # 公众查询页
│   ├── login.php        # 管理员登录页
│   ├── admin.php        # 后台管理页
│   └── api/
│       ├── query.php    # 公开查询接口
│       ├── auth.php     # 登录 / 退出 / 会话
│       └── referees.php # 资格 CRUD / 停用 / 培训记录
├── assets/{css,js}/     # 静态资源
└── data/referee.db      # SQLite 数据库（自动创建）
```

## 启动

```bash
cd referee-system
php -S 127.0.0.1:8000 -t public
```

- 公众查询：<http://127.0.0.1:8000/>
- 后台管理：<http://127.0.0.1:8000/admin.php>
- 默认管理员：`admin` / `admin123`（首次启动自动创建，登录后请尽快更换）

## 安全设计

- **双重校验查询**：编号与姓名必须同时匹配，防止仅凭编号枚举人员信息。
- **权限校验在服务端**：所有管理接口均要求有效会话；写操作强制 CSRF token 校验。
- **参数化查询**：全部 SQL 使用 PDO 预处理，防注入。
- **密码安全**：password_hash / password_verify（bcrypt）存储。
- **敏感目录隔离**：`app/` 与 `data/` 位于 Web 根目录之外。
- 会话 Cookie 设置 HttpOnly / SameSite=Lax，登录成功后 regenerate id，闲置 2 小时过期。

## 资格状态规则

| 状态 | 规则 |
| --- | --- |
| 有效 | 已启用且有效期未过 |
| 即将到期 | 已启用，距到期 ≤ 90 天 |
| 已过期 | 已启用但有效期已过 |
| 已停用 | 管理员手动停用（查询页会显示停用提示） |
